# CakeCosmetic

CakeCosmetic lets a player choose the pictures behind the main menu and the loading screens, unlocked by Monumenta advancements.

## Language

**Background**:
One picture a player can show behind the main menu or the loading screens, supplied by a resource pack.
_Avoid_: Wallpaper, image (that is CakeUI's element type)

**Gallery**:
The screen where a player looks at every background and picks what each place shows.
_Avoid_: Collection, picker

**Unlock rule**:
The advancements a background needs, all of them; a background without one is free.
_Avoid_: Requirement, achievement

**Advancement mode**:
The mode in which a player can only pick backgrounds whose unlock rule they have met on Monumenta; the default.
_Avoid_: Achievement mode, locked mode

**All mode**:
The mode in which every background can be picked, whatever the unlock rules say.
_Avoid_: Free mode, unlocked mode
