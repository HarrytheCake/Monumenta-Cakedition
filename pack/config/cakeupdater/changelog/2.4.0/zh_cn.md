**新增**
- CakeChat 取代 ChatPlus、More Chat History 和 Don't Clear Chat History：多个聊天窗口，带 Monumenta 频道标签页（点击标签页即加入该频道），聊天记录不限条数且切换分片后仍保留，Ctrl+F 搜索，右键复制，按住左 Alt 查看聊天。如果你用过 ChatPlus，它会提示导入你的窗口和标签页。设置：/cakechat。
- Entity Culling 和 Ixeris：在 Market 等人多的地方帧数更高，鼠标和键盘反应更流畅。
- 可选：CakeText Collector 把游戏中的英文文本收集到你电脑上的文件里，供译者使用（从不包括玩家聊天和名字；不会上传任何内容）。

**变更**
- LambDynamicLights 改为可选模组，默认关闭：它在人多的地方很消耗帧数。想保留它，在这次更新询问可选模组时勾选它；以后也可以在安装整合包更新的窗口里点击 “Optional mods...”。
- Cakedition Updater 1.5.0：显示像这样的更新日志；游戏内存过少或过多时提醒一次。
- CakeText Translator 0.3.0（可选）：支持使用你自己密钥的在线翻译服务，并能翻译 CakeWiki 页面。
- CakeBook 指南介绍了新模组，并新增“Java 和内存”一节：我们推荐 Java 21。
- 新安装会使用更快的设置（ImmediatelyFast 告示牌文字缓冲、Nvidium 额外渲染距离 0、关闭 UMM 材质伪装、关闭 spark 后台分析）。已有的安装保留你自己的设置。
