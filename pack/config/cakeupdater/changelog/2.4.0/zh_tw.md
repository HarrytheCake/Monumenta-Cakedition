**新增**
- CakeChat 取代 ChatPlus、More Chat History 和 Don't Clear Chat History：多個聊天視窗，附 Monumenta 頻道分頁（點擊分頁即加入該頻道），聊天記錄不限筆數且切換分片後仍保留，Ctrl+F 搜尋，右鍵複製，按住左 Alt 查看聊天。如果你用過 ChatPlus，它會提示匯入你的視窗和分頁。設定：/cakechat。
- Entity Culling 和 Ixeris：在 Market 等人多的地方幀數更高，滑鼠和鍵盤反應更流暢。
- 選用：CakeText Collector 把遊戲中的英文文字收集到你電腦上的檔案裡，供譯者使用（從不包括玩家聊天和名字；不會上傳任何內容）。

**變更**
- LambDynamicLights 改為選用模組，預設關閉：它在人多的地方很消耗幀數。想保留它，在這次更新詢問選用模組時勾選它；之後也可以在安裝模組包更新的視窗裡點擊「Optional mods...」。
- Cakedition Updater 1.5.0：顯示像這樣的更新日誌；遊戲記憶體過少或過多時提醒一次。
- CakeText Translator 0.3.0（選用）：支援使用你自己金鑰的線上翻譯服務，並能翻譯 CakeWiki 頁面。
- CakeBook 指南介紹了新模組，並新增「Java 和記憶體」一節：我們推薦 Java 21。
- 新安裝會使用更快的設定（ImmediatelyFast 告示牌文字緩衝、Nvidium 額外顯示距離 0、關閉 UMM 材質偽裝、關閉 spark 背景分析）。已有的安裝保留你自己的設定。
