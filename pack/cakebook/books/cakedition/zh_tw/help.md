# 取得協助

遇到 bug、當機或模組異常？請在模組包的 GitHub 頁面回報：

https://github.com/HarrytheCake/Monumenta-Cakedition/issues

請附上：

- 你的**模組包版本**（聊天欄裡的更新訊息會顯示；也可以在遊戲資料夾的 `config/cakeupdater/pack-version.txt` 裡找到）
- 你做了什麼，發生了什麼
- 如果是當機或錯誤：遊戲資料夾裡的 `logs/latest.log` 檔案

關於 Monumenta 本身的問題（任務、物品、職業），請去問 Monumenta 社群：模組包只改變你的用戶端，不改變伺服器。
