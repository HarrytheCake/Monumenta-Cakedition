# CakeUI

讓你按自己的喜好佈置 HUD。它本身不改變任何東西：在你動手修改之前，遊戲畫面和原來一樣。

## HUD 編輯器

在世界裡開啟它：Mod Menu → CakeUI → **編輯 HUD…**，或者點擊 CakeChat 分頁列右端的 **編輯 HUD** 按鈕。也可以在控制設定裡給它設一個按鍵（{key:key.cakeui.editHud}）。

- **拖曳**某個部件來移動它，在它上面**捲動滾輪**來放大或縮小。方向鍵可以微調；按住 Alt 不吸附。
- **右鍵**某個部件可以隱藏它、調整透明度或樣式（例如把生命值顯示成條或數字），或者重設它。
- **右鍵空白處**可以加入你自己的文字、方框、條、圖片、物品或物品欄。圖片放在 `config/cakeui/images/` 裡。
- CakeChat 的視窗和 UMM 的技能列也能在這裡移動。
- Ctrl+Z / Ctrl+Y 復原 / 重做，H 隱藏編輯器面板，**全部重設**恢復原樣。**完成**保存修改；連按兩次 Esc 放棄修改。

你的修改只對你自己生效：它們保存在你電腦上的 `config/cakeui/hud.json5` 裡，模組包更新不會改動它們。
