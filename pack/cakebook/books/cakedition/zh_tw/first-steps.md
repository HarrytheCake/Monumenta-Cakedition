# 新手須知

1. **加入 Monumenta。**伺服器清單裡已經有它了。
2. **檢查你的按鍵。**[按鍵](keys.md)列出了模組包中模組的按鍵，顯示的是你遊戲裡目前的設定。
3. **在啟動器設定裡使用 Java 21，並給 Minecraft 足夠的記憶體。**我們測試的最低值是 4 GB；超過 12 GB 沒有好處，反而可能讓卡頓更久。詳見[Java 和記憶體](performance-tips.md#java-和記憶體)。
4. **選用模組**會在首次安裝時的視窗裡詢問，除非你勾選，否則都是關閉的：
   - Iris 光影載入器，附帶 Complementary Reimagined 光影包
   - Xaero's Minimap（Fair-Play 版小地圖）
   - CakeText Translator（把遊戲中的英文翻譯成中文）
   - CakeText Collector（為譯者收集遊戲中的英文文字）
   - LambDynamicLights（手持火把會照亮周圍；自 2.4.0 起預設關閉）

   之後想更改，在安裝模組包更新的視窗裡點擊 **Optional mods...**。
5. **更新會自動到來。**有新版本時，聊天欄會提示你安裝。詳見[更新與備份](updates.md)。

隨時可以用遊戲選單或物品欄旁邊的書本按鈕，或輸入 `/cakebook` 開啟這本書。
