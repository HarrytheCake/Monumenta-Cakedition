# 工具和前置函式庫

- **Cakedition Updater**：更新模組包和 Monumenta 資源包，並保存備份（見[更新與備份](../updates.md)）。為本模組包製作。
- **Mod Menu**：模組清單及其設定。
- **spark**：找出拖慢遊戲的原因（見[效能建議](../performance-tips.md)）。
- **CraftPresence**：在 Discord 狀態裡顯示你正在玩什麼。
- **AttributeFix**：解除 Minecraft 對屬性數值的限制。
- **YOSBR**：提供模組包的預設設定，但絕不覆蓋你改過的設定。

其他模組需要的前置函式庫（請勿刪除）：Fabric API、Fabric Language Kotlin、Architectury API、Cloth Config、YetAnotherConfigLib、Forge Config API Port、Placeholder API、CICADA、UniLib、Iceberg、Searchables。
