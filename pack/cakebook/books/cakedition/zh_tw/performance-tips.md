# 效能建議

模組包已經針對速度做過調整。如果遊戲仍然不夠流暢：

1. 顯示設定裡的**顯示距離**影響最大，先把它調低。
2. **筆記型電腦：**接上電源。用電池時，很多筆電會大幅降低顯示卡效能。
3. **關閉其他程式**，尤其是瀏覽器和視訊通話。
4. **光影**（選用的 Iris）非常消耗幀數。如果遊戲卡頓，在 顯示設定 → 光影包 中關閉它。
5. **Java 和記憶體：**使用 Java 21，並給遊戲分配合適的記憶體（見下方的「Java 和記憶體」）。

顯示設定由 Sodium 提供，Sodium Extra 增加了更多頁面。按 F3 可以看到幀數。

## 人多的地方

像 Market 這樣擁擠的區域主要考驗處理器而不是顯示卡，所以調低畫質的效果有限。這是正常的。

## Java 和記憶體

我們推薦 **Java 21**。模組包也能在 Java 17 上執行，但 Java 21 較新，遊戲通常更流暢。

在 Prism Launcher 中：

1. 安裝 Java 21，例如 adoptium.net 上的 **Eclipse Temurin 21**（64 位元）。
2. 編輯實例 → **設定** → **Java**。勾選 **Java 安裝**（Java installation），選擇 Java 21（**自動偵測**，或**瀏覽**到它 `bin` 資料夾裡的 `javaw.exe`）。
3. 勾選 **跳過 Java 相容性檢查**（Skip Java compatibility checks）。Prism 只為 Minecraft 1.20.4 提供 Java 17，否則會拒絕 Java 21。

**記憶體**（同一頁的「最大記憶體配置」）：

- 電腦有 8 GB 記憶體：給 Minecraft 4 GB
- 16 GB：6 GB
- 32 GB 或以上：8 GB

不要超過 12 GB：沒有好處，反而可能讓卡頓更久。其他啟動器在 Java 或記憶體設定裡也有相同的選項。

## 回報卡頓

spark 的效能分析能看出時間花在了哪裡：

1. 在卡頓的地方輸入 `/sparkc profiler start`。
2. 玩一兩分鐘。
3. 輸入 `/sparkc profiler stop`。spark 會上傳結果並給你一個連結。

在回報中附上這個連結（見[取得協助](help.md)）。是否上傳由你決定；不執行這些指令就不會傳送任何內容。
