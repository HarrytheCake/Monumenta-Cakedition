# Updates and backups

The pack keeps itself up to date with **Cakedition Updater**.

## Pack updates

When you join a world or server and a new version of the pack is out, a chat message offers two buttons:

- **Update when I close the game myself**: keep playing; the update runs after you quit.
- **Update now (closes the game)**: leaves the server, quits and updates.

After the game has closed, a window installs the update and tells you when to start Minecraft again. The pack never restarts the game for you.

If you installed the pack with Prism Launcher's pre-launch command, updates are also installed every time you start the game.

## Resource pack updates

When a newer Monumenta resource pack is on Modrinth, a separate chat message offers to update it. One click downloads it, puts it in the same place in your pack list and reloads, without a restart.

## Backups

Every time you close the game, your **server list** and **settings** (the config folder) are saved. After a pack update, a chat message offers **[Restore server list]** and **[Restore configs]**, in case the update changed something you liked. The server list comes back at once; configs are put back when you close the game. Whatever you have now is saved first.

All backups: Mod Menu → Cakedition Updater → the settings button, or `/cakeupdate backups`. The last 5 are kept.
