# Tools and libraries

- **Cakedition Updater**: updates the pack and the Monumenta resource pack, and keeps backups (see [Updates and backups](../updates.md)). Made for this pack.
- **Mod Menu**: the list of mods and their settings.
- **spark**: measures what slows the game down (see [Performance tips](../performance-tips.md)).
- **CraftPresence**: shows what you're playing in your Discord status.
- **AttributeFix**: lifts Minecraft's limits on attribute values.
- **YOSBR**: brings the pack's default settings without ever overwriting the ones you changed.

Libraries other mods need (don't remove them): Fabric API, Fabric Language Kotlin, Architectury API, Cloth Config, YetAnotherConfigLib, Forge Config API Port, Placeholder API, CICADA, UniLib, Iceberg, Searchables.
