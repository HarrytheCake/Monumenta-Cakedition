# Chat

- **CakeChat**: the pack's chat: windows, tabs that switch Monumenta's channels, unlimited history, search. Made for this pack: see [CakeChat](../cake/chat.md).
- *Optional:* **CakeText Translator**: shows the game's English text in Chinese. Made for this pack: see [CakeText Translator](../cake/translator.md).
- *Optional:* **CakeText Collector**: collects the game's English text for translators. Made for this pack: see [CakeText Collector](../cake/collector.md).
