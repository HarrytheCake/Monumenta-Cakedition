# Getting help

Found a bug, a crash or a mod that misbehaves? Report it on the pack's GitHub page:

https://github.com/HarrytheCake/Monumenta-Cakedition/issues

Please include:

- your **pack version** (the update message in chat shows it; it's also in `config/cakeupdater/pack-version.txt` in your game folder)
- what you did and what happened
- for a crash or error: the file `logs/latest.log` from your game folder

For questions about Monumenta itself (quests, items, classes), ask the Monumenta community instead: the pack only changes your game, not the server.
