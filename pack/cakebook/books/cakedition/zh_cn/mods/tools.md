# 工具和前置库

- **Cakedition Updater**：更新整合包和 Monumenta 资源包，并保存备份（见[更新与备份](../updates.md)）。为本整合包制作。
- **Mod Menu**：模组列表及其设置。
- **spark**：找出拖慢游戏的原因（见[性能建议](../performance-tips.md)）。
- **CraftPresence**：在 Discord 状态里显示你正在玩什么。
- **AttributeFix**：解除 Minecraft 对属性数值的限制。
- **YOSBR**：提供整合包的默认设置，但绝不覆盖你改过的设置。

其他模组需要的前置库（请勿删除）：Fabric API、Fabric Language Kotlin、Architectury API、Cloth Config、YetAnotherConfigLib、Forge Config API Port、Placeholder API、CICADA、UniLib、Iceberg、Searchables。
