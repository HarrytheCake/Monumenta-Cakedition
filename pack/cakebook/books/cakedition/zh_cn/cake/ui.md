# CakeUI

让你按自己的喜好布置 HUD。它本身不改变任何东西：在你动手修改之前，游戏界面和原来一样。

## HUD 编辑器

在世界里打开它：Mod Menu → CakeUI → **编辑 HUD…**，或者点击 CakeChat 标签栏右端的 **编辑 HUD** 按钮。也可以在控制设置里给它设一个按键（{key:key.cakeui.editHud}）。

- **拖动**某个部件来移动它，在它上面**滚动滚轮**来放大或缩小。方向键可以微调；按住 Alt 不吸附。
- **右键**某个部件可以隐藏它、调整透明度或样式（例如把生命值显示成条或数字），或者重置它。
- **右键空白处**可以添加你自己的文字、方框、条、图片、物品或物品栏。图片放在 `config/cakeui/images/` 里。
- CakeChat 的窗口和 UMM 的技能栏也能在这里移动。
- Ctrl+Z / Ctrl+Y 撤销 / 重做，H 隐藏编辑器面板，**全部重置**恢复原样。**完成**保存修改；连按两次 Esc 放弃修改。

你的修改只对你自己生效：它们保存在你电脑上的 `config/cakeui/hud.json5` 里，整合包更新不会改动它们。
