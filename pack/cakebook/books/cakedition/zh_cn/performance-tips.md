# 性能建议

整合包已经针对速度做过调整。如果游戏仍然不够流畅：

1. 视频设置里的**渲染距离**影响最大，先把它调低。
2. **笔记本电脑：**插上电源。用电池时，很多笔记本会大幅降低显卡性能。
3. **关闭其他程序**，尤其是浏览器和视频通话。
4. **光影**（可选的 Iris）非常消耗帧数。如果游戏卡顿，在 视频设置 → 光影包 中关闭它。
5. **Java 和内存：**使用 Java 21，并给游戏分配合适的内存（见下方的“Java 和内存”）。

视频设置由 Sodium 提供，Sodium Extra 增加了更多页面。按 F3 可以看到帧数。

## 人多的地方

像 Market 这样拥挤的区域主要考验处理器而不是显卡，所以调低画质的效果有限。这是正常的。

## Java 和内存

我们推荐 **Java 21**。整合包也能在 Java 17 上运行，但 Java 21 更新，游戏通常更流畅。

在 Prism Launcher 中：

1. 安装 Java 21，例如 adoptium.net 上的 **Eclipse Temurin 21**（64 位）。
2. 编辑实例 → **设置** → **Java**。勾选 **Java 安装**（Java installation），选择 Java 21（**自动检测**，或**浏览**到它 `bin` 文件夹里的 `javaw.exe`）。
3. 勾选 **跳过 Java 兼容性检查**（Skip Java compatibility checks）。Prism 只为 Minecraft 1.20.4 提供 Java 17，否则会拒绝 Java 21。

**内存**（同一页的“最大内存分配”）：

- 电脑有 8 GB 内存：给 Minecraft 4 GB
- 16 GB：6 GB
- 32 GB 或以上：8 GB

不要超过 12 GB：没有好处，反而可能让卡顿更长。其他启动器在 Java 或内存设置里也有相同的选项。

## 报告卡顿

spark 的性能分析能看出时间花在了哪里：

1. 在卡顿的地方输入 `/sparkc profiler start`。
2. 玩一两分钟。
3. 输入 `/sparkc profiler stop`。spark 会上传结果并给你一个链接。

在报告中附上这个链接（见[获取帮助](help.md)）。是否上传由你决定；不运行这些命令就不会发送任何内容。
