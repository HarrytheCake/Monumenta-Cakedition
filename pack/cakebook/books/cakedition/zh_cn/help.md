# 获取帮助

遇到 bug、崩溃或模组异常？请在整合包的 GitHub 页面报告：

https://github.com/HarrytheCake/Monumenta-Cakedition/issues

请附上：

- 你的**整合包版本**（聊天栏里的更新消息会显示；也可以在游戏目录的 `config/cakeupdater/pack-version.txt` 里找到）
- 你做了什么，发生了什么
- 如果是崩溃或报错：游戏目录里的 `logs/latest.log` 文件

关于 Monumenta 本身的问题（任务、物品、职业），请去问 Monumenta 社区：整合包只改变你的客户端，不改变服务器。
