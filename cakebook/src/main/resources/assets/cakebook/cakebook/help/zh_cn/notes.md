# 你的笔记

你的笔记列在目录底部的**我的笔记**下，最新的在前。搜索也能找到它们。

## 写笔记

1. 点击**新建笔记**（或输入 `/cakebook note <标题>`）。
2. 填写标题并开始书写。**保存**或按 Esc 会保留内容；**取消**会放弃这次的修改。
3. 阅读笔记时，下方会出现**编辑**和**删除**按钮。

## 编辑器里的实用按钮

- **插入位置**：添加你当前所在的位置。安装了 Unofficial Monumenta Mod 时会包含区域和分片，并附上坐标。
- **插入链接…**：选择书中的某一页或另一条笔记，并插入指向它的链接。之后点击链接即可跳转。

## 格式

笔记使用和书一样的简单 Markdown：

- `**粗体**`、`*斜体*`、`~~删除线~~`、`` `代码` ``
- 以 `- ` 或 `1. ` 开头的行是列表项；`# ` 开头是标题；`> ` 是提示框
- `[文字](book:help/notes)` 链接到书页，`[文字](note:my-note)` 链接到笔记，`[文字](https://…)` 链接到网站
- `{key:key.inventory}` 显示你为该操作设置的按键：{key:key.inventory}

## 保存位置

每条笔记都是游戏目录下 `config/cakebook/notes/` 里的一个纯文本文件。复制这个文件夹即可备份，或搬到另一个安装中。
