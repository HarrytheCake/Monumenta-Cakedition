# 你的筆記

你的筆記列在目錄底部的**我的筆記**下，最新的在前。搜尋也能找到它們。

## 寫筆記

1. 點擊**新增筆記**（或輸入 `/cakebook note <標題>`）。
2. 填寫標題並開始書寫。**儲存**或按 Esc 會保留內容；**取消**會放棄這次的修改。
3. 閱讀筆記時，下方會出現**編輯**和**刪除**按鈕。

## 編輯器裡的實用按鈕

- **插入位置**：加入你目前所在的位置。安裝了 Unofficial Monumenta Mod 時會包含區域和分片，並附上座標。
- **插入連結…**：選擇書中的某一頁或另一則筆記，並插入指向它的連結。之後點擊連結即可跳轉。

## 格式

筆記使用和書一樣的簡單 Markdown：

- `**粗體**`、`*斜體*`、`~~刪除線~~`、`` `程式碼` ``
- 以 `- ` 或 `1. ` 開頭的行是清單項目；`# ` 開頭是標題；`> ` 是提示框
- `[文字](book:help/notes)` 連結到書頁，`[文字](note:my-note)` 連結到筆記，`[文字](https://…)` 連結到網站
- `{key:key.inventory}` 顯示你為該操作設定的按鍵：{key:key.inventory}

## 保存位置

每則筆記都是遊戲資料夾下 `config/cakebook/notes/` 裡的一個純文字檔。複製這個資料夾即可備份，或搬到另一個安裝中。
