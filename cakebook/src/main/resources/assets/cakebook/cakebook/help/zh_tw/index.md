# CakeBook

CakeBook 是一本放在遊戲裡的指南書，也是一個小型百科。它會讀取模組包或資源包附帶的書，保存你自己的筆記，並能一次搜尋所有內容。所有內容都只保存在你的電腦上。

## 如何開啟

- 暫停選單裡「回到遊戲」旁邊的**書本按鈕**
- 物品欄右側的**書本按鈕**
- 按鍵：在 選項 → 控制 中設定「開啟指南書」（預設沒有綁定按鍵）。你目前的按鍵：{key:key.cakebook.open}
- 指令 `/cakebook`

書會停在你上次看到的地方。

## 瀏覽

- 左側的**目錄**列出所有書。點擊書名開啟它的第一頁，點擊箭頭可以收合。
- **搜尋**會查找所有頁面和所有筆記，輸入的每個詞都必須出現。按 Ctrl+F 跳到搜尋框。
- **上一頁和下一頁**：`<` `>` 按鈕、滑鼠側鍵，或按 Backspace 回到上一頁。
- **捲動**：滑鼠滾輪、方向鍵、Page Up / Page Down、Home / End。
- 藍色帶底線的文字是連結。開啟網站連結前會先詢問你。

## 指令

所有指令只在你的用戶端執行，不會傳送到伺服器。

- `/cakebook`：開啟書
- `/cakebook open <頁面>`：開啟某一頁，例如 `/cakebook open help/notes`（按 Tab 取得提示）
- `/cakebook search <詞語>`：開啟書並搜尋
- `/cakebook note <標題>`：新增一則筆記
- `/cakebook reload`：修改書之後重新讀取
- `/cakebook folder`：開啟存放你自己的書的資料夾
