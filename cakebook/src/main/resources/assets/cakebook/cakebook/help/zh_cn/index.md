# CakeBook

CakeBook 是一本放在游戏里的指南书，也是一个小型百科。它会读取整合包或资源包附带的书，保存你自己的笔记，并能一次搜索所有内容。所有内容都只保存在你的电脑上。

## 如何打开

- 暂停菜单里“回到游戏”旁边的**书本按钮**
- 物品栏右侧的**书本按钮**
- 按键：在 选项 → 按键控制 中设置“打开指南书”（默认没有绑定按键）。你现在的按键：{key:key.cakebook.open}
- 命令 `/cakebook`

书会停在你上次看到的地方。

## 浏览

- 左侧的**目录**列出所有书。点击书名打开它的第一页，点击箭头可以折叠。
- **搜索**会查找所有页面和所有笔记，输入的每个词都必须出现。按 Ctrl+F 跳到搜索框。
- **后退和前进**：`<` `>` 按钮、鼠标侧键，或按 Backspace 后退。
- **滚动**：鼠标滚轮、方向键、Page Up / Page Down、Home / End。
- 蓝色带下划线的文字是链接。打开网站链接前会先询问你。

## 命令

所有命令只在你的客户端运行，不会发送到服务器。

- `/cakebook`：打开书
- `/cakebook open <页面>`：打开某一页，例如 `/cakebook open help/notes`（按 Tab 获取提示）
- `/cakebook search <词语>`：打开书并搜索
- `/cakebook note <标题>`：新建一条笔记
- `/cakebook reload`：修改书之后重新读取
- `/cakebook folder`：打开存放你自己的书的文件夹
